## Part 4: Step-by-Step Automation Workflow

1.  **Prompt Storage**: All 10 detailed scripts are stored in `reels_data.json`.
2.  **Generation Script**: `generate_reels.py` uses Google Veo 3.1 for cinematic video.
3.  **Scheduling**: GitHub Actions (`reels_automation.yml`) triggers every morning (7am) and evening (8pm).
4.  **Assembly**: MoviePy handles stitching; `instagrapi` handles the automated post.
5.  **Manual Step**: Add professional captions in Filmora if you want the highest quality "Pro" look before uploading, or let the script handle the raw post for full automation.
